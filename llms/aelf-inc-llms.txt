# aelf

> aelf is a Singapore-headquartered, AI-enhanced cloud-native layer-1 blockchain network founded in
> 2017. It is written in C# with a modular multi-side-chain architecture, parallel transaction
> execution and built-in cross-chain communication. Its public machine-readable surface is the AElf
> node Web API — an OpenAPI 3.0.1 contract that every node serves at /swagger/v1/swagger.json — plus
> 89 published protobuf contract definitions, six first-party chain SDKs, a CLI, and a first-party
> agent layer of Agent Skills and a stdio MCP server.

Generated by API Evangelist on 2026-09-09 from the artifacts in this repository. aelf publishes no
llms.txt of its own: /llms.txt was probed on aelf.com, www.aelf.com, docs.aelf.com, blog.aelf.com,
explorer.aelf.io, aelf-public-node.aelf.io and tdvv-public-node.aelf.io and returned 404 everywhere
(explorer.aelf.io answers 200 with its single-page-app shell, which is not a document).

## What you can call

- [aelf Node Web API](https://docs.aelf.com/tools/web-api/): 24 operations across 23 paths — chain
  status, blocks, block state, transaction pool, transaction submission and results, merkle paths,
  contract file descriptor sets, fee calculation, and peer/network management.
- Live mainnet base URLs: https://aelf-public-node.aelf.io (chain AELF) and
  https://tdvv-public-node.aelf.io (side chain tDVV). Both served the identical spec on 2026-09-09.
- Reads are anonymous and free. There are no API keys.
- Writes are authorized cryptographically: you sign a transaction with your own key and POST it.
  POST /api/net/peer and DELETE /api/net/peer are the only Basic-auth operations, and that
  requirement is documented but absent from the contract.

## Agent surface

- [MCP server](mcp/aelf-inc-mcp.yml): first-party, **stdio only** — there is no hosted MCP endpoint.
  Install with `bunx -p @blockchain-forever/aelf-node-skill aelf-node-setup openclaw`. 11 tools.
  Its published inputSchemas are empty permissive objects; the real parameters come from the REST
  operations mapped in the [tool crosswalk](mcp/aelf-inc-tool-crosswalk.yml).
- [Agent Skills](skills/_index.yml): provider-published SKILL.md files (a routing hub and a node
  skill), saved verbatim, plus aelf's own seven-skill catalog.
- No A2A agent card is served on any host.

## How it behaves

- [Conventions](conventions/aelf-inc-conventions.yml) — versioning, pagination, tracing,
  idempotency (partial: exactly-once only on the gateway's send) and reversibility (chain writes
  are final).
- [Error codes](errors/aelf-inc-error-codes.yml) — 13 codes in the 200xx family inside an ABP
  error envelope. Warning: input-format errors come back as HTTP 403, not 400. Read Error.Code,
  not the status.
- [Rate limits](rate-limits/aelf-inc-rate-limits.yml) — none documented, and no rate-limit headers
  on live responses.
- [Plans and pricing](plans/aelf-inc-plans-pricing.yml) — no commercial plans exist. Reads are
  free; writes cost an on-chain fee in ELF, quotable via POST /api/blockChain/calculateTransactionFee.
- [Lifecycle](lifecycle/aelf-inc-lifecycle.yml) — node releases are the versioning story; no
  deprecation policy, no SLA, no status page.
- [Data model](data-model/aelf-inc-data-model.yml) — blocks, transactions, results, log events,
  merkle paths, peers; everything scoped by ChainId.

## Client libraries and tools

- [Packages](packages/aelf-inc-packages.yml) — six first-party chain SDKs (JavaScript, Python, C#,
  Go, Java, PHP). Four of the six were last published in March 2023 against a node that has since
  reached v1.12.1.
- [CLI](cli/aelf-inc-cli.yml) — `aelf-command`, 13 commands.
- [UI components](components/aelf-inc-components.yml) — wallet adapters and a design system.
- [Sandbox](sandbox/aelf-inc-sandbox.yml) — public testnet, faucet, browser playground, and a
  Swagger UI that talks to mainnet.
